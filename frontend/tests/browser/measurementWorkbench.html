Mesures : recherche, sélection et conservation des données

Le vrai composant Oscilloscope utilise des séries de test indépendantes et figées. Tout appel réseau est interdit ; aucun projet utilisateur n’est sollicité.

Depuis un clone installé : npm run dev --prefix frontend -- --port 8882 --strictPort, puis ouvrir /tests/browser/measurementWorkbench.html. Recharger rejoue les contrôles.

Les événements clavier et de presse-papiers sont synthétiques : ils vérifient les gardes et le focus explicite, pas l’ordre de tabulation natif ni la qualité visuelle du rendu.
