# Contrat interne v1 — Atelier Électronique

Python 3.11+, package backend. Projet JSON (dict), valeurs en unités SI numériques.

Project: {schema_version:1,id,title,revision,components:[],wires:[],junctions:[],schematic:{},breadboard:{placements:{},rail_splits:true},ui:{selected:[],view:'split',highlights:[],annotations:[]}}.
Component: {id,kind,label,value,model,pins:{p:'V1.p',n:'V1.n'}}; kinds resistor(p,n), voltage_source(p,n), switch(p,n), button(p,n), diode(a,k), led(a,k), npn(c,b,e), pnp(c,b,e), capacitor(p,n), inductor(p,n), potentiometer(p,w,n), ground(g), voltage_probe(p,n), current_probe(p,n). Model reference generic_npn/generic_pnp/generic_diode, generic_led_red/green/blue. Explicit package pin map in catalog.
Wire: {id,a,b}, a/b refer terminal IDs or explicit junction IDs. Junction {id,x,y}. Schematic dictionary compid:{x,y,rotation}. Placements terminalId:holeId e.g. a1, e1, f1, j1, rail_top_p1; 30 columns. Holes a-e in each column common; f-j common. Rails top/bottom p/n split after column 15 when rail_splits true. Wires and board placements both contribute to SAME electrical connectivity. No implicit joins at line crossings.

backend.domain: new_project(), catalog(), topology(project) -> {nets:[{id,points,holes}],terminal_to_net:{},hole_to_net:{}}, validate_topology(project)->list diagnostics. ground net id '0'; others stable deterministic IDs. Store(project=None, path=None), get_state()->{project,topology,catalog,simulation,history:{can_undo,can_redo}}, transact(expected_revision,operations,preview=False), undo(expected_revision), redo(expected_revision). Store stores simulation dict; Store.project available, lock RLock. Store methods return full state, errors raise ValueError. Constructor creates a default useful 5V/1kohm circuit if project is None (via new_project default if practical).
Operations: add_component {kind,id?,value?,label?,x?,y?,model?}; move_component {id,x,y}; set_value {id,value}; set_model {id,model}; connect {a,b,id?}; remove_component {id}; remove_wire {id}; add_junction {id?,x,y}; remove_junction {id}; place_pin {terminal,hole:null|string}; set_ui {selected?,view?,highlights?}; annotate {text,targets?}; set_title {title}; set_rail_splits {enabled}. Each op has key type. All transactions atomic, validated, expected_revision required. Preview does not mutate revision/history. UI changes may use transactions too.

backend.simulation: simulate(project, analysis=None,cancel_event=None)->result dict. analysis {kind:'op'|'tran',step:0.0001,stop:0.01}. Result {status:'success'|'error'|'cancelled',project_revision,voltages:{netId:number},currents:{compId:number},time:[],curves:[{id,label,unit,values:[]}],diagnostics:[],log,netlist,assumptions:[]}. Currents convention from first listed terminal to second (BJTs collector into device). Return actual ngspice data only. CPU/memory/time/point limits. Stop process on cancel. Module example_projects()->dict[str,project] in backend.examples (ohm, divider, diode, npn, pnp, rc, subtractor). run_truth_table(project, inputs, outputs, cases, thresholds?, cancel_event?)->dict; inputs map label/compId to source ID, outputs map label to terminalId; cases list {inputs:{label:0|1},expected:{label:0|1}}; use 0/5V, independent copies, collect measured volts, logic, expected observed convergence. threshold low=1.5 high=3.5.

backend.server FastAPI app on 127.0.0.1:8765 serving built frontend/dist. API GET /api/state, GET /api/health, POST /api/transaction {expected_revision,operations,preview?}, POST /api/undo and /api/redo {expected_revision}, POST /api/simulate {analysis?} (can await thread so stop route responsive), POST /api/stop, GET /api/examples -> list {id,title}, POST /api/load-example {id,expected_revision}, POST /api/truth-table {example?:'subtractor',...}, POST /api/save, GET /api/export, POST /api/import {project,expected_revision}. Full state returned for mutation routes. /api/state polling every ~750ms sync MCP changes. Security: loopback, Origin allowlist, token generated local .runtime/token for write calls X-Atelier-Token, GET /api/health gives token only to same-origin local UI (or separate /api/session). Prefer UI gets token in /api/state? document exact API choice. No filesystem access from client, fixed authorized project save path.
MCP stdio bridge via official Python SDK. backend.mcp_server forwards tools to local HTTP API sharing its state (token read fixed .runtime/token, URL fixed localhost/config via env with validation), never own separate Store. Full protocol integration test uses official client subprocess. Tool list includes read circuit/revision, inspect, topology, continuity, models, UI, simulate/stop/results/truth table/highlight/annotate/transaction/preview/undo/redo. No arbitrary shell/files tools.


Extension atelier : LED kind led(a,k), modèles generic_led_red/green/blue, défaut rouge. Potentiometer(p,w,n), value résistance totale 1Ω–1GΩ, position∈[0,1] défaut0.5 ; set_position {id,position}. Segment p-w=max(1mΩ,R×position), w-n=max(1mΩ,R×(1-position)). currents[id] entrant p ; terminal_currents p/w/n tous entrants.
Voltage source waveform? {kind:'pulse',low,high,delay,rise,fall,width,period} ; toutes valeurs SI finies, niveaux ±1MV, delay>=0, autres durées>0, rise+width+fall<=period. set_waveform {id,waveform:null|object}. OP=low ; TRAN=PULSE typé. add_component conserve waveform, position et capacitor.initial_voltage. move_junction {id,x,y}.

Inductor : value en H, [1e-12,1e6], défaut0.01, préfixeL, pins p/n. Élément ngspiceL idéal, courant réel positif p→n exposé dans currents[id] et curves I:<id> unitéA. OP=court-circuit, TRAN avecUIC courantinitial0A; startup:false partdeOP. Aucun paramètre initial_current dans cette version. Instrument UI Énergie : ½C(Vp−Vn)² et ½LI² enJ depuis mesures fraîches; séries agrégées indisponibles si un élément manque, jamais de repli sur un dernier succès après échec.
Wire color?:hex6|null, waypoints?:[{x,y}] maximum32, coordonnées finies±1e6 ; set_wire_style {id,color?,waypoints?}. Champs graphiques ignorés dans circuit_fingerprint et electricalSignature.
Library GET /api/projects->{projects:metadata[],capacity:12}; POST /api/projects/save {expected_revision}->{projects,capacity,saved}; POST /api/projects/load {id,expected_revision}->State ; POST /api/projects/delete {id}->{projects,capacity}. Identifiants saved_<uuid32>, fichier fixe runtime/projects.json, copies indépendantes bornées, aucune éviction automatique.

Balayage POST /api/parameter-sweep {expected_revision,component_id,values:[number]2..16,probe?:{p:terminalId|'0',n:terminalId|'0'}}. Cible resistor.value, voltage_source.value sans waveform, potentiometer.position. Chaque variante est prévalidée. Retour {status,project_id,project_revision,circuit_fingerprint,parameter,probe,total,completed,converged,rows:[{index,value,voltage:number|null,current:number|null,status,diagnostics}],elapsed_seconds,assumptions}. OP réel sur copies indépendantes, échéance45s, même verrou/arrêt que simulation ; projet, historique et résultats actifs conservés.

Historique : les transactions uniquement set_ui incrémentent la révision et sont persistées mais ne créent pas d’entrée undo et ne vident pas redo. Un undo/redo dans le même projet conserve les champs UI modifiés depuis la dernière édition, en filtrant les références disparues. Les transactions mixtes restent une édition atomique complète.

Presse-papiers UI : format JSON `atelier.circuit-fragment`, version 1 ; MIME `application/x-atelier-circuit+json` avec repli texte brut. Champs autorisés : components/junctions/wires/schematic ; jamais de projet complet, implantation, mesure, annotation ou opération arbitraire. Maximum 1 000 000 octets et 499 opérations avant sélection finale. Collage en une transaction, identifiants réservés à l’exécution, connexions internes seulement ; les masses restent le 0 V commun. Les textes étrangers, champs et dialogues gardent leur comportement natif.

Multi-plaques : breadboard.board_count?:int1..4 défaut1. Trous première plaque inchangés a1 ; autres plaques '2:a1', '3:rail_top_p1', etc. Aucun alias '1:a1' ou '02:a1'. set_board_count {count} refuse la suppression d’une plaque portant des bornes. Bandes/rails disjoints entre plaques ; connexions explicites par wires, masses globales inchangées. Un composant physique garde ses pattes sur une seule plaque ; source/masse/sondes sont des raccordements externes. layout_breadboard couvre12parties physiques×board_count. Nombre de plaques vides ignoré par l’empreinte électrique.
